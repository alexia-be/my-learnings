# My Learnings

This is where I keep the projects I build while learning to code. Most of them follow a course or tutorial, and in each project's README I note what I took from the course and what I added myself.

## How this repo is organized

Each project has its own folder with its own README, which covers what it does, the tools used, and what I learned.

```
my-learnings/
├── README.md
└── project-name/
    ├── README.md
    └── ...
```
